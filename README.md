Video Game Sales Analysis
This project focuses on analyzing video game sales data to understand sales performance across different platforms, genres, publishers, years, and regions. The analysis was performed to identify market trends, top-selling games, regional preferences, and factors influencing global sales.
The project helped me practice Python-based data analysis, data cleaning, exploratory data analysis (EDA), aggregation, and data visualization using a real-world dataset.
Objectives
•	Identify the top-selling video games based on global sales.
•	Analyze sales performance across different gaming platforms.
•	Determine the most successful game genres.
•	Study the influence of publishers on sales performance.
•	Analyze sales across North America, Europe, Japan, and other regions.
•	Examine changes and trends in video game sales over different years.
Dataset
The dataset contains information about video games and their sales performance. Important columns include:
•	Rank – Overall sales ranking
•	Name – Game name
•	Platform – Platform on which the game was released
•	Year – Release year
•	Genre – Game genre
•	Publisher – Game publisher
•	NA_Sales – Sales in North America
•	EU_Sales – Sales in Europe
•	JP_Sales – Sales in Japan
•	Other_Sales – Sales from other regions
•	Global_Sales – Worldwide sales
Analysis Performed
1. Top-Selling Games
•	Sorted games according to Global_Sales.
•	Identified the highest-selling games.
•	Calculated total global sales using aggregation.
2. Platform Analysis
•	Grouped sales by Platform.
•	Calculated total global sales for each platform.
•	Used visualizations to compare platform performance.
3. Genre Analysis
•	Compared global sales across different genres.
•	Identified high-performing genres.
•	Studied genre trends across different years and platforms.
4. Publisher Analysis
•	Aggregated sales by publisher.
•	Identified top-performing publishers.
•	Compared publisher performance across regions.
5. Regional Sales Analysis
•	Compared sales contributions from North America, Europe, Japan, and other regions.
•	Analyzed regional preferences and sales trends.
•	Used visualizations to understand regional differences.
Tools & Techniques
Tools: Python, Jupyter Notebook, Pandas, Seaborn, Matplotlib
Techniques Used:
•	Data inspection and cleaning
•	Missing-value analysis
•	Descriptive statistics
•	groupby() and aggregation
•	Sorting and filtering
•	Exploratory Data Analysis (EDA)
•	Histograms and box plots
•	Bar charts
•	Stacked bar charts
•	Trend analysis

Conclusion
Through this project, I gained practical experience in handling datasets, cleaning and preparing data, performing EDA, analyzing categorical and numerical variables, applying Pandas aggregation techniques, and creating meaningful visualizations. I also learned how to convert raw sales data into insights related to platforms, genres, publishers, regions, and market trends.The Video Game Sales Analysis project demonstrates how Python and data analysis techniques can be used to study the performance of the gaming industry. By analyzing global, regional, platform-wise, genre-wise, and publisher-wise sales, the project provides a structured approach to understanding video game market trends and sales patterns.
